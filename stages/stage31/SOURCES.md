# Sources

SwiftShader describes itself as a CPU-based Vulkan 1.3 implementation and documents that its ICD is loaded through the Vulkan loader; on Linux the ICD can be selected through the generated `vk_swiftshader_icd.json`. See the canonical SwiftShader repository.

The Vulkan specification defines `VK_FORMAT_R8G8B8A8_UNORM` as a standard RGBA8 format and the normal resource/image pipeline used in this stage.

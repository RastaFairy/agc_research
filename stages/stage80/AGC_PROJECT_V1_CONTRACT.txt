AGC PS5 Stage 80 - Project Integration ABI v1 Contract

PURPOSE
=======
Stage 80 creates a project-facing adapter layer on top of Stage 79.

WHAT IS NOW CONSUMABLE
======================
- agc_abi_v1.h
- libSceAgcDriver_abi_v1.a
- agc_project_v1.h
- libagc_project_v1.a

ABI FACTS CARRIED FORWARD
=========================
- SubmitCommandBuffer: RDI=context, RSI=record
- record accessed at +0x00 width 8
- record accessed at +0x08 width 4
- record accessed at +0x0C width 1
- dispatch table stride = 0x78
- global +0xA4 is used as a dispatch-table index
- global +0xA0 is used as a dispatch-table bound/count-like value
- SubmitDcb / AgrSubmitDcb wrappers use the exact Stage79 two-argument ABI

IMPORTANT LIMIT
================
This adapter deliberately retains opaque names field_00/field_08/field_0c.
The final public semantic names are not yet proven.
The library is therefore suitable as an ABI-v1 project integration layer,
not as a final semantic SDK replacement.

REAL AGC EXECUTION
==================
Not performed in Stage 80.
